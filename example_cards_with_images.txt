# Fencing Spaced Repetition - Export Format V3
# This file demonstrates the V3 export format with base64-encoded images and GZIP compression
#
# Format: TSV (Tab-Separated Values) with GZIP compression (.tsv.gz)
# Columns: Question | Answer | ImagePaths(double-pipe-separated-base64) | Algorithm | StateContext | NextReview | LastReview |
#          FSRS_Stability | FSRS_Difficulty | FSRS_State | FSRS_Reps | FSRS_Lapses |
#          FSRS_ScheduledDays | FSRS_ElapsedDays | SM2_EaseFactor | SM2_Interval |
#          SM2_Repetitions | Groups(pipe-separated)
#
# Notes:
# - Images are base64-encoded and separated by "||" (double pipe)
# - Newlines in questions/answers are escaped as "<br>"
# - File should be compressed with GZIP before saving
# - StateContext is "GLOBAL" for global state, or a group name for group-specific state
#

# USAGE INSTRUCTIONS:
#
# To import this file:
# 1. The file must be GZIP compressed with .tsv.gz extension
# 2. Use the import function in the app
# 3. Images will be automatically decoded and saved to internal storage
#
# To create your own export:
# 1. Use the export function in the app
# 2. File will be automatically compressed with GZIP
# 3. Share the .tsv.gz file
#
# Technical details:
# - Base64 encoding uses NO_WRAP flag (no line breaks)
# - GZIP compression typically reduces file size by 60-80%
# - Images are stored as JPEG/PNG in internal storage after import
# - File format is backwards compatible with V1/V2 (without images)
